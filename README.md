# 🌐 Desenv-Web

🧠 Repositório de estudos do curso **"Domine Web: 20 cursos em 1"** da **Udemy**, ministrado pelos professores **Jamilton Damasceno** e **Jorge Sant Ana**.

Aqui organizo todos os projetos, exercícios e anotações que estou desenvolvendo durante o curso, que cobre desde o **front-end básico** até o **back-end com PHP, MySQL, MVC e APIs**, incluindo até desenvolvimento com **Ionic**.
